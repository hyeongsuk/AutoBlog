# 네이버 블로그 자동화 글쓰기 프로그램

Selenium과 Google Gemini AI를 활용한 네이버 블로그 자동 포스팅 시스템입니다.

## 주요 기능

### 1. 블로그 자동화
- 네이버 자동 로그인 (보안 우회 방식 적용)
- 블로그 글쓰기 페이지 자동 접근
- 제목 및 본문 자동 입력
- 임시 저장 기능
- 인간적인 타이핑 모방 (ActionChains 활용)

### 2. AI 콘텐츠 생성
- Google Gemini API를 활용한 자동 콘텐츠 생성
- 키워드 기반 제목 및 본문 생성
- 엑셀 파일 대량 처리 지원
- SEO 최적화된 콘텐츠

## 설치 방법

### 1. 저장소 클론
```bash
git clone <repository-url>
cd AutoBlog
```

### 2. 필요한 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 3. 환경 변수 설정
`.env.example` 파일을 `.env`로 복사하고 정보를 입력합니다:

```bash
cp .env.example .env
```

`.env` 파일 내용:
```
# 네이버 계정 정보
NAVER_ID=your_naver_id
NAVER_PW=your_naver_password

# Google Gemini API (선택 사항 - AI 콘텐츠 생성 시 필요)
GEMINI_API_KEY=your_gemini_api_key
```

### 4. Google Gemini API 키 발급 (선택 사항)
AI 콘텐츠 생성 기능을 사용하려면 Google Gemini API 키가 필요합니다.

1. [Google AI Studio](https://makersuite.google.com/app/apikey) 접속
2. API 키 생성
3. `.env` 파일에 `GEMINI_API_KEY` 설정

## 사용 방법

### 방법 1: 기본 블로그 자동화 (수동 입력)
```bash
python 블로그_글쓰기_자동화.py
```

코드 내에서 제목과 본문을 직접 수정하여 사용합니다.

### 방법 2: AI 콘텐츠 생성 + 자동 포스팅
```bash
python ai_blog_automation.py
```

실행 후 모드 선택:
- **1번**: 수동 입력 (직접 제목과 본문 입력)
- **2번**: AI 콘텐츠 생성 (키워드만 입력하면 AI가 자동 생성)
- **3번**: 엑셀 대량 생성 (엑셀 파일의 키워드로 여러 포스트 생성)

### 방법 3: AI 콘텐츠만 생성 (테스트)
```bash
python ai_content_generator.py
```

## 엑셀 파일 형식 (대량 생성 시)

엑셀 파일은 다음 형식으로 준비하세요:

| A열 (키워드) |
|-------------|
| 키워드1     |
| 키워드2     |
| 키워드3     |

- 첫 번째 행은 헤더로 사용됩니다 (건너뜀)
- A열에 키워드를 입력하세요
- 각 키워드마다 별도의 블로그 포스트가 생성됩니다

## 주요 기술

- **Selenium**: 브라우저 자동화
- **pyperclip**: 클립보드 복사/붙여넣기 (보안 우회)
- **ActionChains**: 자연스러운 타이핑 모방
- **Google Gemini AI**: 콘텐츠 자동 생성
- **openpyxl**: 엑셀 파일 처리

## 주의사항

⚠️ **중요: 책임있는 사용**

1. **개인 블로그 용도로만 사용하세요**
   - 이 프로그램은 본인의 블로그를 효율적으로 관리하기 위한 도구입니다
   - 스팸이나 악의적인 목적으로 사용하지 마세요

2. **네이버 이용약관 준수**
   - 네이버 블로그 이용약관을 반드시 확인하고 준수하세요
   - 자동화 도구 사용이 제한될 수 있습니다

3. **계정 보안**
   - `.env` 파일을 절대 공개하지 마세요
   - Git에 업로드되지 않도록 `.gitignore`에 포함되어 있습니다

4. **API 사용량 제한**
   - Google Gemini API는 무료 사용량 제한이 있습니다
   - 대량 생성 시 요금이 발생할 수 있으니 확인하세요

5. **콘텐츠 품질**
   - AI가 생성한 콘텐츠는 반드시 검토 후 수정하세요
   - 저작권이나 사실 관계를 확인하세요

6. **로그인 보안**
   - 2단계 인증이 설정된 계정은 자동 로그인이 불가능할 수 있습니다
   - 필요 시 2단계 인증을 임시 해제하고 사용하세요

## 문제 해결

### 로그인 실패
- 네이버 계정 정보가 정확한지 확인하세요
- 2단계 인증을 해제하세요
- Captcha가 나타나면 수동으로 입력해야 할 수 있습니다

### 제목/본문 입력 실패
- 네이버 블로그 UI가 변경되었을 수 있습니다
- 셀렉터(CSS Selector)를 업데이트해야 할 수 있습니다

### AI 콘텐츠 생성 오류
- `GEMINI_API_KEY`가 올바르게 설정되었는지 확인하세요
- API 사용량 제한을 확인하세요

### 브라우저 드라이버 오류
- Chrome 브라우저가 최신 버전인지 확인하세요
- `webdriver-manager`가 자동으로 드라이버를 다운로드합니다
